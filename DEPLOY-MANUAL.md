## (b) booking.php — the server's copy needs the same edits
The repo's `booking.php` (regenerated by `_build.py`) now accepts `event_time` and whitelists `callback_time` + `event_time`. **The cPanel `.cpanel.yml` does NOT copy `booking.php`** (it only copies `*.html`, `styles.css`, `script.js`, `assets/`), so a normal "Deploy HEAD Commit" will NOT update the server's `booking.php`. You must update it by hand.

Exact diff (against the previous `booking.php`):

```diff
@@ $allowed list
- $allowed = ['event', 'guests', 'date', 'hall', 'email', 'message', 'callback_time', 'website'];
+ $allowed = ['event', 'guests', 'date', 'hall', 'email', 'message', 'callback_time', 'event_time', 'website'];
@@ before $line = json_encode(...)
+ $cb_ok = ['Morning', 'Afternoon', 'Evening'];
+ $et_ok = ['Morning', 'Afternoon', 'Evening', 'Night'];
+ if (isset($data['callback_time']) && $data['callback_time'] !== '' && !in_array($data['callback_time'], $cb_ok, true)) {
+     $data['callback_time'] = '';
+ }
+ if (isset($data['event_time']) && $data['event_time'] !== '' && !in_array($data['event_time'], $et_ok, true)) {
+     $data['event_time'] = '';
+ }
 $line = json_encode($data, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES) . PHP_EOL;
```

Notes:
- `guests` was already optional (no validation error if absent) — no change needed there.
- `booking.php` writes a JSON line to `enquiries.log`; there is no email-sending code in it, so the new fields are stored in the JSON record only. (`booking-store.php` was not touched, per the rules.)
- To apply: open the server's `/home/venutaihall/public_html/booking.php` in cPanel File Manager and make the two edits above (add `event_time` to the `$allowed` array; insert the whitelist block right before `$line = json_encode(...)`). Back up the file first.
